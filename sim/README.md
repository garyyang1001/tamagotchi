# 桌機模擬器

在 Mac 上跑真正的 `assets.bin` 和真正的 `firmware/src/game.c`，
三顆實體按鍵用鍵盤代替。

```bash
make -C sim run
```

**只有 `sim/main.c` 是桌機專屬的。** 遊戲邏輯、渲染層、資產存取
和燒進 ESP32 的是同一份原始碼——ESP32 那一層只要換掉「誰提供畫布、
誰把畫布推到螢幕上」。

## 為什麼先做桌機

渲染層的錯（座標、調色盤、RLE 解碼）在這裡五分鐘看得到，燒到板子上要五分鐘一輪。
這裡跑通之後，硬體那一層只剩 SPI LCD 驅動和按鍵 GPIO。

## 按鍵

| 鍵 | 作用 |
|---|---|
| `←` / `A` | 上一個 |
| `空白` / `Enter` | 確認 |
| `→` / `D` | 下一個 |
| `P` | 電源鍵（關機動畫兩秒；期間按三顆操作鍵任一顆可取消） |
| `B` | 切電量：滿 → 充電中 → 20% → 5% → 滿 |
| `N` | 快轉一小時（看夜間、看需求衰減） |
| `V` | 催一隻訪客進來（平常要閒置好幾分鐘） |
| `1`–`5` | 直接換第 n 套服裝 |
| `0` | 全戴／全脫配件 |
| `S` | 存一張 PPM 到 `build/sim_shot.ppm` |
| `ESC` / `Q` | 離開 |

## 主畫面怎麼走

游標停的每一格都是**房間裡看得見的實體**：

```
🚪 門 → 呼叫寵物（換狗不必先送回去）
👗 衣櫃 → 換裝
💡 開關 → 休息（關燈／開燈）
👸 公主 → 互動選單（4 個，她沒有 bladder）
🐕 狗   → 互動選單（5 個），只在有狗在場時存在
```

標記分兩種，判準是「接不接地」：角色站在地上給地板箭頭，
門／衣櫃／開關在牆上給紅框。

## 無視窗自檢

```bash
./build/icepet-sim --shots build/shots
```

跑一段固定腳本，把每個畫面各存一張 PPM。不需要顯示器、不需要人按鍵——
改完渲染層用它確認沒有畫壞。
