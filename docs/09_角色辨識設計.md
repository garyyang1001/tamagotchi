# 09 — 角色辨識設計

> 本文件回答一個問題：**怎麼讓 3 歲小孩在 64px 的 sprite 上認出「這是我們家那隻」。**
>
> 三隻狗共用同一個物種剪影，這比一般的角色設計難得多。
> 以下多數規則來自發展心理學研究，不是美術品味。

---

## 一、推翻的假設：剪影不是最重要的

業界的角色可讀性階層是 **剪影 → 明度 → 色相 → 細節**。
Valve 的 TF2 論文把「填黑仍可辨識」寫進了正式技術文件。

**但這個階層是為了區分不同物種／職業而設計的。**

我們的三隻都是狗。剪影的「狗」層級是共享的，
所以**剪影只能告訴小孩「這是狗」，不能告訴他「這是哪一隻」**。

兩個發展心理學的發現讓這件事更嚴重：

### 形狀偏誤（shape bias）

約 18–24 個月起，兒童優先依**形狀**（而非大小、顏色、材質）類推物體標籤。

對三隻狗來說，形狀就是「狗」這個類別的線索。
**形狀偏誤會讓小孩把三隻都歸成同一類。** 顏色與表面特徵必須接手。

### 3 歲無法整合維度

維度轉換卡片分類作業（DCCS）顯示，典型的 3 歲兒童會**固著**，
無法在「按顏色分類」和「按形狀分類」之間切換；4 歲才能靈活切換。
研究形容這種僵化「與前額葉皮質受損的病患相似」。

**硬性約束**：

> 每隻狗要有**一個壓倒性的主線索**，其他線索是冗餘備援，不是必要條件。
> 三條頻道必須**互相對齊、指向同一個答案**，而不是分工。

「棕色的大狗 vs 棕色的小狗」這種需要同時考慮兩個維度的設計，對 3 歲是有風險的。

## 二、假二分法：寫實 vs 可愛

Rhodes 等人（1992, *Memory & Cognition*）的**超肖像效應**：

> 誇大了特徵偏差的漫畫像，**比真實照片更容易被辨識**。

機制是：臉是以「相對於原型的特徵偏差」被編碼的，誇大偏差等於強化大腦實際存的東西。

所以「保留真實特徵」和「可愛化」不衝突。正確的做法是：

1. 列出每隻狗**相對於「通用狗」的偏差**
2. 把偏差**放大 1.3–1.5 倍**
3. **其餘一切往可愛化的方向簡化**（圓化、大眼、短肢）

個體身分只存在於偏差裡。**所有非偏差的部分本來就沒有身分資訊，
拿來換可愛度是零成本。**

參考案例 *Stray*：主角以真實流浪貓 Murtaugh 為原型，但遊戲裡的貓
「不是真貓的精確複製品」——團隊只保留橘色與鼻斑兩個標誌，其餘一般化。

## 三、三頻道識別系統

每隻狗一個「一個詞的身分」，在三條頻道上**同時說同一件事**。
任一條頻道單獨都足以辨識。

### `chihuahua` — 棕白長毛吉娃娃

| 頻道 | 內容 |
|---|---|
| 剪影詞 | **小 + 巨耳 + 蓬** |
| 明度詞 | **最亮**（灰階下三隻裡最白） |
| 色相詞 | 白／奶油為主 |

- 高度做到最大那隻的 **60–65%**。體型差距要誇張，不照真實比例
- 耳朵**放大 1.3–1.5 倍**，大而直立的三角。這是牠最大的偏差，吃滿它
- 長毛**只做輪廓粗糙度**——胸前、後腿後方、尾巴做成剪影上的鋸齒凸起。
  **不要在身體內部畫毛絲**
- 尾巴上舉、羽毛狀、捲向背部（三隻裡最有動感的尾巴）
- 白色佔比要高，那是牠的明度身分

### `brown_mixed` — 巧克力棕厚實米克斯

| 頻道 | 內容 |
|---|---|
| 剪影詞 | **厚實 + 矮胖（桶狀）** |
| 明度詞 | **中深身體 + 亮色口鼻**（臉上的高對比） |
| 色相詞 | 溫暖巧克力棕 |

- 中等高度但**最寬**。粗短腿、短脖子、低平尾巴、圓潤輪廓
- **灰白口鼻是最好的禮物，吃滿它**：做成一整塊蓋住臉部前緣的淺色面具，
  比真實範圍大。在 20×20 的臉上，這是唯一能穩定讀出來的臉部特徵——
  因為它是**明度對比**，不是細節
- **眉毛兩點淺褐是整個專案投報率最高的像素花費**
  - 每點做成 **2×2 以上的方塊，不要細橫條，更不要 1×1**
  - 單像素在小孩的視距下會消失
  - 位置正對每隻眼睛上方，與眼睛之間留 1px 深色毛隔開
- **這兩點 + 淺色口鼻 ≈ 這隻狗的全部身分，其他細節都可以砍**

### `brindle_guard` — 棕黑虎斑護衛犬

| 頻道 | 內容 |
|---|---|
| 剪影詞 | **最大 + 最高 + 最方** |
| 明度詞 | **最暗**（灰階下三隻裡最黑） |
| 色相詞 | 深棕黑 + 焦褐點綴 |

- 佔滿高度預算（100%），約為吉娃娃的 **1.5–1.7 倍**。長腿、深胸、平直背線、直立耳
- **虎斑絕對不要照畫**。真實虎斑在 64px 會變成雜訊。改成
  側腹 **3–5 條粗直深色帶，每條 2px 寬，中間留清楚空隙**，後腿再 2 條。
  當成「大貓條紋」處理——少而粗
- 加上焦褐斑點（tan points）：口鼻、眉點、胸口、下肢
- ⚠️ **牠的眉點必須在形狀上和 `brown_mixed` 明顯不同**，否則兩隻會混淆。
  建議這隻用細長條，`brown_mixed` 用方點

## 四、項圈：整份研究裡槓桿最大的一件事

> **如果三隻狗現實中戴不同顏色的項圈，直接用真實顏色。**

讓遊戲裡的線索和現實裡的線索**完全是同一個**，
3 歲小孩不需要額外學習任何映射。這比任何美術技巧都有效。

### 顏色選擇規則

3 歲兒童約 2.5–3 歲開始能辨認顏色，多半只知道一種，4 歲才會知道多種。

**用最基本、最能命名、彼此差距最大的顏色**（紅／黃／藍／綠這個層級）。
不要用「淺褐 vs 巧克力棕」這種需要細膩色彩詞彙的區分。

每個項圈色必須同時滿足：
1. 三者之間**色相和明度都拉開**
2. 每個都和**自己那隻狗的身體**有對比

若無真實顏色可用，建議配置：

| 角色 | 項圈色 | 理由 |
|---|---|---|
| `chihuahua` | 深洋紅／粉 | 深色配件壓在最亮的身體上 |
| `brown_mixed` | 黃綠／萊姆 | 色相與明度都遠離棕色 |
| `brindle_guard` | 亮紅／橘 | 高明度配件壓在最暗的身體上 |

### 領巾優於項圈

項圈在 64px 只有 2px 寬（約 15–20 個像素）。
**領巾在胸前有 30–50 像素的純色塊**，遠距離和運動中都好認。

代價是會蓋掉胸口標記。取捨依真實情況——狗現實中戴什麼就做什麼。

## 五、臉部：不要把身分押在這裡

眼動研究顯示 4–10 歲兒童看狗臉的注視模式與辨識準確度都和成人不同，
要能正確判讀狗的表情**可能需要明確訓練**，而人臉靠日常互動就夠了。

**推論**：20×20 的臉、3×3 的眼睛，即使畫得再精確，3 歲小孩也不太可能靠它辨識。

臉部區域的像素預算應該花在**大塊的明度對比**（眼罩、口鼻面具、眉點），
**不是五官精度**。

超級瑪利歐的極限案例：Mario 的眼睛只是上下疊起來的兩個像素，耳朵也是。

眼睛只給 1px 瞳孔 + 1px 高光就夠。多的預算移到眉／眼罩區域。

## 六、動畫是第四條識別頻道

3 歲小孩讀動作的能力遠好過讀細節，而且這條頻道**成本極低**——
「位移一兩個像素」就是一個轉頭。

給每隻狗**不同的節奏**：

| 角色 | 節奏 | idle 週期 |
|---|---|---|
| `chihuahua` | 高頻、抖動、小幅跳躍、耳朵頻繁抽動 | **最短** |
| `brown_mixed` | 慢、沉、低幅度，偶爾一個大哈欠或搖頭 | **最長** |
| `brindle_guard` | 穩定、警覺，頭部左右掃視，耳朵定期轉向 | 中等，幅度最大 |

在小孩看不清像素的距離下，這條頻道仍然有效。

## 七、兩層表現法

參考 *Dog Sled Saga*：**64px sprite 不必獨力承擔個體識別**。

搭配一組更大的頭像（128×128 或更大）放在選單、對話框、狀態列，
在那裡把眉點、灰口鼻、虎斑完整畫出來。

小孩會透過大圖學會「哪個標記對應哪隻狗」，再把這個知識帶回小 sprite。

---

## 八、64px 上的特徵取捨

### 必須保留（依價值排序）

1. **整體體塊與高度比例** — 剪影層，零成本
2. **耳型與耳朵姿態** — 資訊密度最高的犬類特徵，4–8px 就能讀
3. **頭／口鼻輪廓** — 剪影層
4. **尾巴形狀與姿態** — 剪影層，而且**會動**，動畫中最顯眼
5. **大色塊的明暗分區**（2–3 塊）— 改的是分配，成本為零
6. **毛長 → 只做輪廓粗糙度** — 剪影層的免費資訊
7. **一個簽名標記，超比例放大** — 超肖像效應的著力點

### 直接捨棄

個別毛絲、毛流紋理、虹膜／瞳孔分離、眼白、鼻孔、嘴線、鬍鬚、
腳掌肉墊、腳趾、爪子、寫實肌肉起伏、真實關節比例、
單一色塊內的微妙色階、項圈的扣環與狗牌。

## 九、驗收測試

上線前跑這五個。前四個我可以自己跑，第三個必須是真人。

1. **填黑剪影測試** — 三隻填成純黑，1× 縮放下能分出誰是誰嗎？
   分不出就改體型／耳朵／尾巴
2. **灰階測試** — 去色後三隻的整體明度是否明顯不同？
   （`chihuahua` 最亮 / `brown_mixed` 中 / `brindle_guard` 最暗）
3. **3 歲測試（最重要）** — 在**實際目標螢幕上、1× 縮放、手臂距離、只看 1 秒**。
   問「這是哪一隻？」**不要問「這是不是 XX？」**（避免引導）
4. **運動測試** — 走路動畫播放中，遮住畫面 80%，只露一小塊，能認出嗎？
5. **色盲檢查** — 不要讓身分只靠紅 vs 綠

### 一條紀律

> **設計定案後，標記位置在所有影格和所有姿勢中都不能移動一格。**

繪本研究顯示孩子會察覺圖案的變動——髮型改變、衣服圖案換掉、比例不對，
他們都注意得到。這在像素美術裡很容易犯：換個姿勢隨手把眉點移了一格，
小孩會察覺不對勁。

## 十、現況檢查（`brown_mixed`）

| 標記 | 現況 | 判定 |
|---|---|---|
| 灰白口鼻 | 12×11，88px，亮度 186 vs 身體 55.7 | ✅ 對比 130，很強 |
| 眉點（近） | 4×2 | ⚠️ 是細橫條不是方點 |
| 眉點（遠） | 3×2 | ⚠️ 同上 |
| 眼睛高光 | 2px | ✅ 正確，不該花預算 |
| 身體明度 | 55.7（49.7% 面積） | 待與另外兩隻比對 |

待辦：眉點加高成方點；三隻都做完後跑灰階測試確認明度分離。

## 附錄：四個角色做完之後的實測驗證

本文件前面的論證是**設計前**寫的。四個角色全部定稿之後回頭量，結論如下。

### 量到的數字

| 角色 | 剪影 | 面積 | 平均亮度 | 亮度標準差 | 主色相 | 影格格 |
|---|---|---|---|---|---|---|
| `brown_mixed` | 64×54 | 1809 | 61.3 | 40.9 | 0° | 64×56 |
| `brindle_guard` | 50×55 | 1253 | 95.7 | 61.5 | 30° | 64×56 |
| `chihuahua` | 44×36 | 986 | 120.7 | 75.3 | 0°（白色占 17.8%） | 64×56 |
| `ice_princess` | 38×90 | 2298 | 161.5 | 61.7 | **210°** | 64×96 |

### 三條頻道各自成立嗎

**剪影：成立，而且比預期強得多。** 本文第三節說「剪影是分辨同種個體最弱的一條頻道」——
那個結論**只在同尺寸時成立**。三隻填黑之後仍然是三個完全不同的形狀：
厚實垂耳、精瘦立耳、蓬鬆巨耳加捲尾。體型從 1809 到 986 差了 45%，
這一條是免費的、而且是三歲小孩最先讀到的。

**明度：成立。** 61 / 96 / 121 / 162，四個位置間距各約 35，灰階下排序穩定。

**色相：對其中一組失效。** `chihuahua` 和 `brown_mixed` 的主色相都是 0-30° 的褐色帶。
實測牠的巧克力 `#5E432E`（色相 26°、明度 37%）正好落在
`brown_mixed` 的 `coat_mid #4A3225` 與 `coat_light #66452F` 中間。
**這兩隻的毛色分不開，而且改不開**——真實的狗就是這個顏色，鐵律 5 不允許改。

補救不是「換一個褐色調」，是**換一條頻道**：`chihuahua` 有 17.8% 的純白
（另外兩隻是 0.1% 與 0.2%）。牠的一句話身分因此是「有白色的那隻」，
不是「巧克力色的那隻」。

### 給第四個角色（冰雪公主）的結論

1. **先量再設計。** 「感覺不一樣」不是證據。這三隻的色相衝突是量出來才發現的，
   而且是在第三隻做到一半時才發現——早一點量可以省一次重做。
2. **體型是最便宜的頻道。** 不用畫任何東西就有，而且對三歲小孩最有效。
3. **一條頻道失效不是災難，前提是還有兩條。** 色相在 chihuahua↔brown_mixed 上失效，
   但剪影（1809 vs 986）與明度（61 vs 121）都還在，所以整體仍然分得開。
   真正危險的是三條同時只差一點。
4. 公主是**人形**，剪影上和三隻狗天生就不同——實測填黑之後一眼分得出。
   她挑到明度 161.5 與色相 210°，兩條都落在三隻狗完全沒佔的位置。
   **色相對她是最強的頻道**，剛好補上三隻狗之間最弱的那一條。

### 第五個角色（如果有）要注意的

明度已經佔掉 61 / 96 / 121 / 162，剩下的空位只有 <50 或 >190，兩端都很極端。
色相佔掉 0° / 30° / 210°，還很空。所以下一個角色應該**從色相下手**
（綠、紫、青），不要再往明度擠。
