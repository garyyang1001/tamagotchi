## 階段 3：韌體

依賴順序：

```
存檔層 ✅
  ↓
資產載入（flash mmap + RLE 解碼 + PSRAM LRU 快取）
  ↓
渲染層（LVGL 或自寫 sprite blitter + DMA to SPI LCD）
  ↓
動畫狀態機
  ↓
遊戲邏輯（需求衰減 / 夜間模式 / 里程碑）
  ↓
觸控互動
  ↓
音效（I2S + IMA-ADPCM）
  ↓
電源管理（light sleep / deep sleep）
```

**先做「一隻狗在螢幕上呼吸」這個最小可跑目標**，
它會一次串起資產包、解碼、渲染、動畫狀態機四層。跑通之後其餘都是重複。

| 風險 | 影響 | 對策 | 狀態 |

| AI 逐張生成動畫會漂移 | 資產全部報廢 | 改走部件切分 + 烘焙 | ✅ 已解 |
| 250 張 RGB565 塞不進 flash（7.81 MB） | 專案做不出來 | 4bpp 索引 + RLE，降到 ~900 KB | ✅ 已解 |

| 逐格量化造成色彩閃爍 | 動畫品質 | 固定調色盤 | ✅ 已解 |
