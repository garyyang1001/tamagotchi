# 01 — 硬體選型與 BOM

> 本文件是**建議選型**。實際採購前請對照供應商規格書確認型號與腳位，
> 尤其是模組上的 flash / PSRAM 容量標示（同一個外觀的板子常有多種配置）。

## 選型結論

| 項目 | 選擇 | 關鍵理由 |
|---|---|---|
| MCU | **ESP32-S3, 16 MB flash, 8 MB PSRAM** (`N16R8`) | PSRAM 放整張 framebuffer；16 MB flash 給資產留餘裕；原生 USB 可直接燒錄與充電 |
| 螢幕 | **2.8" IPS 320×240 SPI** | 四角色同框需要 320 寬（見下方尺寸計算）；IPS 可視角對桌面裝置重要 |
| 觸控 | **電容式**（非電阻式） | 3 歲手指按不動電阻式；電容式輕觸即可 |
| 音效 | **I2S DAC + 8Ω 1W 喇叭** | 要放真實的狗叫聲，PWM 蜂鳴器做不到 |
| 電池 | 3.7 V LiPo 2000 mAh + 充電管理 | 需完全封閉在外殼內 |
| 實體按鍵 | 1 顆（電源 / 喚醒） | 其餘互動全靠觸控 |

## 為什麼是 320×240 而不是 240×240

原始規劃給的角色尺寸有衝突。四角色同框時：

```
公主 120 + 中大型犬 104 + 中大型犬 104 + 小型犬 72 = 400 px
```

240 和 320 都放不下。解法是**兩套縮放比例**（由 baker 自動產生，不需額外美術）：

| profile | 用途 | 公主 | 大型犬 | 吉娃娃 | 同框總寬 |
|---|---|---|---|---|---|
| `solo` (100%) | 單角色互動特寫 | 96×128 | 112×88 | 68×56 | — |
| `group` (70%) | 全家福 / 多角色場景 | 68×90 | 78×62 | 48×40 | **272 px** ✓ |

272 < 320，加上前後錯位（Z 軸深度交疊）看起來自然。240 寬則仍然塞不下。

## 記憶體與頻寬驗算

**Framebuffer**
```
320 × 240 × 2 bytes (RGB565) = 153,600 B = 150 KB
```
ESP32-S3 內部 SRAM 512 KB，硬塞得下但會排擠其他配置。放 PSRAM，
以 DMA 送到 SPI LCD。PSRAM octal 模式頻寬約 40–80 MB/s，
30 fps 需求為 `150 KB × 30 = 4.6 MB/s`，餘裕充足。

**SPI 傳輸**
```
320 × 240 × 16 bit = 1,228,800 bit
@ 80 MHz SPI ≈ 15.4 ms / 全螢幕更新 ≈ 65 fps 理論上限
```
實務上算 30–40 fps。動畫只需 6–12 fps，且多數更新是局部重繪，非常寬裕。

**Flash 分區規劃（16 MB）**

| 分區 | 大小 | 用途 |
|---|---|---|
| bootloader + partition table | 64 KB | |
| `nvs` | 24 KB | 設定值（音量、亮度） |
| `savegame` | 8 KB | **自管 A/B 雙槽存檔**（見 `04`） |
| `app0` | 3 MB | 韌體 |
| `app1` | 3 MB | OTA 備援（可選；不做 OTA 可省下給資產） |
| `assets` | 6 MB | 資產包，`spi_flash_mmap` 直接讀取 |
| `logfs` (LittleFS) | 3.8 MB | 事件記錄 + 音效檔 |

資產實際用量估算約 **0.7–1.2 MB**（見 `05` 的壓縮計算），6 MB 分區有 5 倍餘裕。

## BOM

### 方案 A：一體式開發板（**建議第一版走這條**）

市面上有整合好 ESP32-S3 + 2.8" 電容觸控 LCD + 鋰電管理的板子，
Waveshare、Elecrow、Makerfabs、LilyGO 都有這個品類。買一體板可以省掉：
排線焊接、背光電路、觸控 I2C 上拉、電池保護板。對做 1–2 台的專案這是正確選擇。

**採購時必須逐項確認的規格**（不要只看照片）：

- [ ] MCU 標示為 **ESP32-S3**（不是 ESP32 或 ESP32-C3）
- [ ] Flash **≥ 8 MB**，PSRAM **≥ 2 MB**（最好 16 MB / 8 MB）
- [ ] 螢幕 **320×240 以上**，IPS，驅動 IC 有公開的 LVGL / TFT_eSPI 支援
- [ ] 觸控為 **電容式**（常見 IC：CST816S、FT6236、GT911）
- [ ] 有 **鋰電池座 + 充電 IC**
- [ ] 有 **I2S 腳位可用**（接音效模組）
- [ ] 廠商提供 **pin map 文件與範例程式碼**（沒有的話不要買，除錯會很痛苦）

### 方案 B：分件組裝

| 項目 | 型號建議 | 數量 |
|---|---|---|
| MCU 模組 | ESP32-S3-WROOM-1-N16R8 開發板 | 1 |
| 螢幕 | 2.8" IPS 320×240 SPI，ILI9341 或 ST7789 驅動 | 1 |
| 觸控 | 電容觸控板，CST816S / FT6236（I2C） | 1 |
| 音效 DAC | MAX98357A I2S 功放模組 | 1 |
| 喇叭 | 8Ω 1W 小喇叭 | 1 |
| 電池 | 3.7V 2000mAh LiPo，**必須含保護板** | 1 |
| 充電 | TP4056 + 保護（若開發板未內建） | 1 |
| 按鍵 | 輕觸開關 6×6mm | 1 |
| 外殼 | 3D 列印（PLA 或 PETG） | 1 |

## 安全要求（3 歲使用者，不可省略）

這是給幼兒長期接觸的物品，以下為硬性要求：

1. **鋰電池必須完全封閉**。外殼用螺絲鎖固，且螺絲不可從外部徒手或用湯匙開啟。
   使用內含保護板（過充 / 過放 / 短路保護）的電池芯，不要用裸電芯。
2. **無小型可拆件**。任何直徑小於 3 cm 的可拆部件都是吞嚥風險，設計上直接避免。
3. **外殼全圓角**，最小圓角半徑 2 mm，無銳邊、無夾手縫隙。
4. **螢幕加保護層**（0.5 mm PET 或壓克力），避免玻璃破裂。
5. **若加掛繩，必須是斷開式（breakaway）**，不可用固定式繩環——纏繞窒息風險。
6. 充電時的表面溫度控制在 **45 °C 以下**。
7. 3D 列印材料用 PLA 或 PETG，**不要用 ABS**（列印逸散物）。避免使用有塗料的表面處理。

## 電源與續航

- 動畫閒置時降到 6 fps，且只重繪變動區域
- 無觸控 30 秒 → 背光降至 30%
- 無觸控 3 分鐘 → light sleep，觸控中斷喚醒
- 夜間（可設定，預設 20:30–07:00）→ deep sleep，只保留 RTC 計時

粗估：亮螢幕約 150–200 mA，2000 mAh 電池約 **10–13 小時連續使用**，
以幼兒實際使用模式（每天斷續 1–2 小時）約可撐 **5–7 天**一充。
